- 方案:新增 `styles/fx.css` + `scripts/fx.js` 两个增量文件,index.html 只加 2 行引用(fx.js 须在 ui.js 之后,用到其全局 showToast 和 body[data-active-panel])。

## 第二轮:全空间叙事重构(journey 模式)
- 小唐想要「大门开场 + 空间纵深穿越」式导航,选了最彻底的全空间叙事方案。
- 新增 `styles/journey.css` + `scripts/journey.js`(仍在 fx 层之上增量叠加,index.html 各加 1 行)。
- 核心机制:body.journey 下隐藏侧边栏;panels-wrap 加 perspective:1000px 变 3D 场景;journey.js 包装 window.switchPanel(ui.js 的函数声明是全局可变的,包装后主题/星空/active 类逻辑全部复用);rAF 每帧给 7 个面板写 translate(-50%,-50%) translateZ(camZ-z),站间距 1500px,按距离算透明度;只有 |tz|<60 的站加 .dock 类开放交互。
- 输入:滚轮/方向键/触摸滑动,长内容面板(skills/game)用 scrollTop 边缘检测——先滚内容,滚到头才切站;游戏区(activePanel==='game')放行方向键给游戏。
- 右侧星图导航 .jmap(7 站,可跳站,跳站会穿过中间站);左上 .jbrand 迷你 logo 点击回首页;底部航行提示滚一次后消失。
- 大门开场 #fx-gate:拱门两扇门叶 rotateY 打开 → gate-inner scale(7.5) 穿越;sessionStorage 'sj-gate'='seen' 每会话只看一次。
- 飞行拖影 #fxWarp canvas:径向光线,密度随相机速度,开门时 boost。
- reduce-motion 用户:journey.js 直接 return,整站回退经典翻页模式(重要降级设计)。
- 调试钩子:window.Journey.flyTo(name)。

## 第三轮:精致化修正(小唐的三条反馈)
1. 滚动条碍眼 → journey 模式下 `.panel` 隐藏滚动条(scrollbar-width:none + webkit display:none),滚动能力保留。
2. 下一站内容太明显 → 可见性参数收紧:FADE_FAR -2600→-1450, FADE_IN -700→-500, PASS_OUT 180→120, GONE 520→480。停靠时相邻站 op=0 完全不可见,只在飞行途中浮现。另加距离模糊:远处/掠过站 blur 最高 4px,停靠站无模糊。
3. 大门太小、遮不住首页 → #fx-gate 改为不透明星空幕布(background-color:#04060f + CSS 星点渐变);门体 min(230px,44vw)→min(340px,58vw),标题放大;相机初始 camZ=-900(停在门外),点击开门 fly 时 targetZ=0 滑入首页,形成「往里走」动线。
