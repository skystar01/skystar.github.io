### 线上 404 诊断与修复
- 用户报告 GitHub Pages 打开后无法交互；控制台 `GET https://skystar01.github.io/src/main.js 404`。
- 根因：线上 index.html 引用 `<script type="module" src="/src/main.js">`（开发态入口），GitHub Pages 不执行 Vite build、只静态托管；`/src/main.js` 在线上拿不到 → 模块入口 404 → 整站（背景/UI/特效/游戏壳全在 app.js）未初始化 → 点不动。**直接把 Vite 仓库当静态站托管行不通。**
- 修复：
  1. 新增 `.github/workflows/deploy-pages.yml`：push main / 手动触发；build(npm ci → npm run build → upload-pages-artifact dist) + deploy(deploy-pages@v4)。
  2. `.gitignore` 取消 `package-lock.json` 忽略（供 CI `npm ci` 复现）。
  3. 本地已 commit `0eadfac`。
