### 优化动作
1. 游戏 JS 拆懒加载：`src/app.js` 首屏段 + 新建 `src/games-bundle.js`（9 个游戏），game-shell 改 `async setActiveByGame` + `ensureGamesBundle()` 首次切游戏时 `import('./games-bundle.js')`；plane 维持独立 `game-plane.js` 懒加载。
2. 游戏 CSS 懒加载：index.html 移除 7 个游戏 `<link>` + plane `<link>`，改为 `games-bundle.js` / `game-plane.js` 顶部 `import '../styles/...css'`（Vite 自动切异步 CSS chunk）。
3. **修了一个真实拆分 bug**：`showToast` 定义在首屏 `app.js:460`（未挂 window），游戏里裸调用 `showToast('未连接 Flask…')` → 拆模块后 ReferenceError。修复：`app.js` 加 `window.showToast = showToast`，games-bundle 两处改走 `window.showToast`。
