### window.switchPanel is not a function（最新修复）
- Action 部署 dist 成功后用户报新错：`Uncaught TypeError: window.switchPanel is not a function`（控制台指向 index-DLSPMkdq.js）。
- 根因：阶段1 模块化时 `switchPanel` 定义在 `src/app.js` 模块作用域，从没挂 `window` 总线。但代码里多处通过 `window.switchPanel(...)` 调用（键盘 Home/End 1556/1582/1583、按钮点击 1611/1627、journey 段）；更关键的是 `app.js:1433` `var origSwitch = window.switchPanel;` 在包装前读取——因当时 `window.switchPanel` 为 undefined，1435 行的 `if (typeof origSwitch === 'function')` 不成立 → 包装器**根本没安装** → `window.switchPanel` 永久 undefined。这是与 showToast bug **同类**的 window 总线遗漏。
- 修复：`app.js` 在 `switchPanel` 定义后（约 443 行）加 `window.switchPanel = switchPanel;`（类比 showToast 在 472 行的写法），确保在 1433 包装前挂好。
- 防御性扫描：grep 全仓 `window.xxx(` 调用点，逐一确认均有对应总线暴露（setStarTheme 286、showToast 472、switchPanel 新、startPlaneGame game-plane.js:3598、snakeGame/fitGomoku/fitMemory/mazeGame games-bundle.js、activateFocusTrap/deactivateFocusTrap 381/382）。确认无其它同类隐患。
- 验证：`npm run build` ✅ 产物主包 `index-BRZd1Ft0.js`（hash 由 DLSPMkdq 变更）。grep 产物确认 `window.switchPanel=Le`（原始函数）与 `window.switchPanel=function`（1435 包装器）两处都在，逻辑闭环。
